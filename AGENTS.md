## Voice transcription

This user dictates almost everything. Treat unclear words as possible homophones or speech-to-text errors before you ask.

When you reinterpret something, say so once in this form and keep going:

> I'm assuming you meant [reinterpretation] when you said "[original]". Let me know if I got that wrong.

The user will not acknowledge a correct reading. They will correct you only when you guessed wrong. Do not wait for confirmation, and do not ask again about the same phrase.

Examples:
- "push it to the Maine branch" → assume "push it to the main branch"
- "open a pool request" → assume "open a pull request"
- "spin up an easy to instance" → assume "spin up an EC2 instance"
